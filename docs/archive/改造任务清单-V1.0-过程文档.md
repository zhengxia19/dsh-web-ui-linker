## 0. TL;DR 一句话方案

给包补上**浏览器半边（client 插件）**：在侧边栏底部 `sidebar.footer.action` 席位注册一个按钮；点击时按钮向宿主半边的新 webServer 路由 `GET /web-ui-linker/url` 发同源 fetch（浏览器自动带认证 cookie），宿主实时用 `ctx.connection.authenticatedUrl()` 计算含**最新启动 token** 的 URL 返回；按钮拿到后执行 `window.open(url)`。在 Electron 桌面壳里，`window.open` 的 http/https URL 会被主窗口的 `setWindowOpenHandler` 转交给 `shell.openExternal(url)` —— 即**系统默认浏览器**；在真实浏览器里则自然变成新标签页。现有"把 URL 写入 `web-ui-url.txt`"的行为完整保留。

## 2. 平台机制研究结论（含证据索引）

### 2.1 桌面应用 = Electron 壳 + Node 宿主，GUI 就是网页
- Electron 主进程（asar 内 `shell/main.js`）spawn `dsh-desktop-host`，宿主回报 `{type:"ready", url, …}`，url 由 `ctx.connection.authenticatedUrl(protocol//127.0.0.1:port)` 生成，Electron 用它加载主窗口。
- **决定性事实**：主窗口注册了窗口打开处理器（asar 提取件 `extracted\shell\main.js:11970-11973`）：
  ```js
  window.webContents.setWindowOpenHandler(({ url }) => {
    if (["http:", "https:"].includes(new URL(url).protocol)) shell.openExternal(url);
    return { action: "deny" };
  });
  ```
  → 页面里任何 `window.open(http…)` 都会**交给系统默认浏览器**（`shell.openExternal`），且 Electron 不弹新窗口。这就是"默认浏览器打开"的官方通路，无需 electron 桥（http 页面上 `window.dshDesktop` 只有 `{protocolVersion:1}`，无 openExternal 桥）。

### 2.2 插件浏览器半边的挂载机制（无需打包器）
- 包在 package.json 声明 `dsh.client = { platform: "web", inject?, external?, immediately? }`（字段校验见 `dsh-client-modules/lib/index.js` 的 `parseDshClient`，L62-76），并导出 `./client` 子路径。宿主扫描 profile 里已启用的条目，自动把其 client bundle 以服务地址 `plugins/<pkg>/client.js`（combo 脚本 `plugins/??a/client.js,b/client.js…&rev=<hash>`）注入 index，并生成启动线 `window.__DSH_BOOT__ = {rev, release, entries:[{id,url,rev,inject,…}]}`。host 启用即 client 启用，无独立开关。
- bundle 格式 = 手工可写（官方格式）：
  ```js
  window.__ModuleLoader__.load({ id: "<包名>", factory: (require) => { … return module.exports } })
  ```
  `module.exports.apply = (ctx) => …`、`module.exports.inject = ["slots"]`。factory 里 `require("react")` 是**基座种子词**（无需打包，`dsh.client.external` 只列基座之外的请求；同机先例未列任何 external 就用了 `react`）。
- **同机活先例**（最贴近的模板）：`D:\Code\DPH_plug\dsh-system-prompt-manager`
  - `package.json`：`"exports": {"./client": "./client/client.js"}`、`"dsh": {"client": {"inject": ["@deepseek-ai/dsh-client-runtime"], "platform": "web"}}`、无构建脚本；
  - `client/client.js`（14.5KB 手写）：`__ModuleLoader__.load` → `React.createElement` 组件 + CSS 字符串注入 → `ctx.slots.inject('conversation.input.left', () => ctx.slots.register(...))`；
  - 与宿主通信：普通**相对同源 fetch** `fetch('/dsh-spm/' + endpoint)`（页面已由 cookie 认证），宿主用 `ctx.webServer.register({kind:'exact', path:'/dsh-spm/…'})` 应答（`lib/index.js:164-165`）。

### 2.3 按钮在 DPH 里的位置（slot 系统）
席位目录内嵌于 `dsh-cordis-client-runner/lib/client.js`（提取件 L5651-5697）。目录摘录：

| 席位 | kind/scope | 目录描述 | 现有占用 | 适配度 |
|---|---|---|---|---|
| **`sidebar.footer.action`（推荐）** | list / root | "Optional actions beside Settings at the sidebar foot."（侧边栏底部、设置旁的可选动作；`wide` 由宿主给，56px 窄栏/宽栏两态） | client-ui-cordis `CordisPanel id:'cordis-panel'`（图标+角标面板） | ✅ 图标按钮的天然位置；`replaceRisk: none`；register 需 `id`，可选 `order`/`label` |
| `shell.bottom` | single | 页面底部条 | — | ⚠️ 全局横幅感，不适合一个动作 |
| `settings.general.item` / `settings.section` | — | 设置页条目 | — | ⚠️ 藏得深，"一键打开"变三步 |
| `conversation.session.header.actions` | list | 会话头部动作 | open-in-app 的 "Open In…" 分体按钮 | 备选：语义是"对当前会话/工作区做事"，与本插件"对宿主整体拿 URL"不完全吻合 |
| `sidebar.panellist` | list | 全局面板图标（宿主拥有按钮） | — | ⚠️ 语义是"打开面板"，点击行为由宿主定义，不能自定义 fetch→window.open |

注册示例（目录原文）：
```js
return { inject: ['slots'], apply(ctx) {
  ctx.slots.inject('sidebar.footer.action', () => ctx.slots.register(
    { name: 'sidebar.footer.action', id: 'my-entry', order: 100, label: 'My entry' },
    () => React.createElement('div', null, 'hello'),
  ))
}}
```
> 注意：`id` 必须用自己的新 id（复用已出厂 id 会**替换**那个格子）。建议 `id: 'web-ui-linker'`，`order: 120`（排在 cordis-panel 之后，顺序按升序）。

### 2.4 宿主路由与鉴权
- `ctx.webServer.register({ kind:'exact', path, handler(req,res) })`；匹配顺序 **exact → 最长 prefix → fallback**（`dsh-host-webserver` README），SPA fallback 不会截走我们的 exact 路由；用 `ctx.effect(...)` 挂载以获得 fiber 生命周期。
- **webServer 本身无全局认证**；`/api` 与 open-in-app 的路由都在 handler 里调 `ctx.connection.admit(req)`：先 Host/Origin 信任（防 DNS rebinding/跨站），再 cookie/API 认证，失败返回 401/403（`dsh-client-connection/lib/index.js:855-871, 1045-1058`；README："请求须通过部署的浏览器认证与主机来源信任检查"）。
- 我们的路由返回的是**含 token 的完整认证 URL**（泄露即可接管 GUI API），比先例 `/dsh-spm`（未设防）更应设防 → **必须走 `admit`**。页面自身 fetch 自动携带 host-only 认证 cookie，按钮流程无感。
- token 是**每进程随机启动 token**；页面地址在 303 后不含 token；只有宿主能实时算 `authenticatedUrl`。所以 URL 必须每次点击时现取，不能编译期或页面缓存。

### 2.5 备选打开方式（对比后不选）
| 方案 | 结论 |
|---|---|
| **A. 页面 `window.open(url)` → Electron handler → `shell.openExternal`** | ✅ 选定：零宿主进程副作用、跨平台、真实浏览器=新标签页（符合直觉） |
| B. 宿主端 spawn `cmd /c start <url>`（或 `xdg-open`/`open`） | 可行但需 subprocess 依赖、平台分支、URL 引号转义风险；仅作兜底记录 |
| C. `dsh-apiproxy` 的 `openPath`（官方 README 提及） | desktop profile 未装 apiproxy，不引入 |
| D. 导航当前页 `location.href = url` | ❌ 会把 GUI 自己重定向成登录流程 |

## 3. 目标设计

```
[DPH 主窗口 GUI 页面]                            [Electron 壳]                [系统默认浏览器]
按钮(sidebar.footer.action, 本插件 client 半)
  │ click → fetch GET /web-ui-linker/url  (同源, 自动带 cookie)
  ▼
[本插件 host 半] webServer exact 路由
  ctx.connection.admit(req)  ── 403/401 ──►
  实时 authenticatedUrl(base) → {url, clean, token, generatedAt, origin}
  │ JSON
  ▼
按钮: window.open(url, "_blank", "noopener")  ──setWindowOpenHandler──►  shell.openExternal(url)  ──► 默认浏览器打开带 token 的登录 URL
（真实浏览器场景：window.open 直接新标签页；把 origin 改写为 location.origin，见 T3.4）
```

保留行为：轮询写 `web-ui-url.txt` / 状态文件的既有逻辑一字不动（路由复用同一份"最新读数"缓存，另加点击时强制刷新一次）。

### T1 host 半：新增 `GET /web-ui-linker/url` 路由（改 `lib/index.js`）
- [x] T1.1 读数实现为 `readCurrent(ctx)`：每次调用实时计算 `{url, clean, token, origin, generatedAt}`（比模块级缓存更稳，路由每请求取现值）。
- [x] T1.2 注册路由（`apply()` 里 `ctx.effect` 立即注册，端口未就绪时路由回 503；linktest 工装实机确认 `route registered: GET /web-ui-linker/url`）：
  ```js
  ctx.effect(() => ctx.webServer.register({
    kind: "exact",
    path: "/web-ui-linker/url",
    handler: (req, res) => {
      if (req.method !== "GET" && req.method !== "HEAD") { res.writeHead(405); res.end("method not allowed"); return }
      const admission = ctx.connection.admit(req)          // 信任 + cookie/API 认证
      if ("rejection" in admission) {
        res.writeHead(admission.rejection)
        res.end(admission.rejection === 401 ? "unauthorized" : "forbidden")
        return
      }
      res.writeHead(200, { "content-type": "application/json", "cache-control": "no-store" })
      res.end(JSON.stringify(latest ?? (/* 端口已就绪则立即算一次 */ null)))
    },
  }), "web-ui-linker:http")
  ```
